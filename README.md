# Flujo comun de Git

1. Traer los cambios

    ```bash
    git fetch

    git pull origin main

2. Estado actual del repositorio local (ver como va tu version)

    ```bash
    git status

3. Agregar los cambios a capa staging
    ```bash
    git add .

4. Generar el commit
    ```bash
    git commit - "Mi primer commit en github"

5. Empujar los cambios

    ```bash
    git push origin main
